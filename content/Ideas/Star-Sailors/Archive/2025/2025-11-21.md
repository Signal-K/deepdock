# Star-Sailors Ideas — 2025-11-21

Source: [[Operations/Daily/Archive/2025-11/2025-11-21.md|2025-11-21.md]]

## Extracted Ideas
So I think the new idea of building a Stardew Valley-type game, where you farm honey, is an idea.
Each flower or crop type will obviously produce different nectar, there needs to be some sort of data dictionary for this...but I still don't know what types of crops we're going to start with when in production.

Building houses and settlements is one way to go about things, but to be honest, I don't want to build another farming game set in some sort of fictional small town. I don't want to romanticise leaving the "city life" - I'm (to be completely honest) sick of that bullshit.

However, I don't really know a good setting for the narrative (I don't think space is plausible at this point), so I'm just going to build up the foundations like the countless other SV clones for now.

For pollination, what we'll say is that bees at random times during the day will leave the hive and fly around, if they're clicked on, they open up the classification dialogue. This adds extra nectar to the hive, nectar also pools up throughout the day based on the bees in each hive.
