What are the key features/parts that adding Supabase supports?
1. Multiplayer missions
2. Visiting others' bases/environments
3. Backups

I guess the first thing would be is adding a backup support for users who are logged in. So #Supabase #Authentication needs to be added here.

Rather than adding a live-action multiplayer version, because that would take too long, I'll allow users to export a code that if they find something interesting, they can share the code which will allow users to see a target (and the environment that it was part of) in their preview....but it won't be interactable/importable for the second user (yet)


I think going forward, the larger visual assets e.g. `Launchpad.png` should be composed of ~10+ smaller images so we have 1) higher res 2) increased AI accuracy 3) more malleability.

Users will get bonuses for sharing/referring others; as well as their contributions in other games in the Star Sailors universe. Finally, we could potentially introduce a mechanic where users can trade resources on a simple marketplace and then add "bug bounty" type mechanics late
