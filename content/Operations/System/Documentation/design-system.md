## Color Coding Standards

### Project-Specific Colors
Based on [[Physical-Notes/2025-12-15#Page 76 - Bumble Simple Proposal|Bumble analysis]]:
- **RED:** Critical systems, tickets, errors, writing
- **BLUE:** UI components, dividers, navigation
- **GREEN:** Ambitious features, future plans
- **BLACK:** Core/stable components
