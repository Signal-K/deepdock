So, we're starting off with ten levels and a sandbox level. I think we could probably get away with four fish species, two coral species, 

![[Pasted image 20251227100422.png]]
To begin with, I think what I'll do is I'll pick two simple corals (`Antipathes atlantica` and `Antipathes furcata`) and create them in `Pixilart.com`. Then, I'll pick four fish species (I'll go through the "Collect" discussion points on Zooniverse to see if there's any specific actually mentioned). In contrast to the original plan, I will **not** be using fictional names for the coral.

* [ ] Find four fish species
* [ ] Draw coral
* [ ] Draw fish
* [ ] Decide fish species names

I'm still not quite set on how the actual build process is going to work...

Users will get the classification daily mission in the sandbox level. 

The key question is how to make the sandbox level not a "thirty second task, once a day and check-back" type interface like most of the #Star-Sailors-web platform is right now. It needs to feel like another level.
