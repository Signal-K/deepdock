Users should be able to view their classifications in the following areas:
1. `/inventory/classifications` - a list of all classifications, along with the `view`, `inspect` and `visit` buttons (as applicable)
2. Viewports - each viewport shows classifications (as a #Classification-Icon) that belong to the projects/missions that are accessed by that viewport ^b8dee8

Users should be able to view all classifications (not just their own) in the following areas:
1. Viewports - see [[#^b8dee8]]
2. `/vote/awaiting` - do we add this route? 

## Voting and Community Classification Participation

Users should be able to view classifications they’ve made, those awaiting consensus/voting, and those they can contribute feedback to.

Voting contributes toward consensus accuracy and should reward the player with a small amount of Stardust. Over time, consensus participation will unlock badges and skills, encouraging players to help vet the community’s discoveries.

These entries should appear in the sidebar or activity feed, and clicking them opens a modal for review.

We’ve proposed a new "Awaiting Voting" view in the sidebar. This will list classifications that have not yet reached consensus and allow users to contribute votes.
