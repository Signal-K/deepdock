# Accessing the generator
1. From their classification inventory - `/inventory/classifications` -> `planets` section (see [[Viewing a user's classifications & contributions]])
2. After they make the initial classification - `/next/${classificationId}`
3. From the #Classification-Icon in a #Viewport 

# Limitations
We'll lock certain sliders if the user hasn't done a classification or comment of certain values

## Planet Customization and Painting

Planet customization may eventually allow players to adjust or "paint" their discovered planets based on unlocked stats. For example, using temperature data to change color ranges, or biomass data to add flora layers.

These creative tools may live in a sandbox view where players can manipulate planetary data, supported by data collected during inspection missions (e.g. spectroscopy).

Research tasks or achievements could unlock new painting tools or visual layers.
