# Inbox - Quick Capture Zone

This folder is for quickly capturing ideas, notes, and thoughts that you'll organize later.

## Usage

1. Create new notes here when you need to jot something down quickly
2. Don't worry about organization - just write
3. Periodically review and move notes to appropriate project folders
4. Use tags to help with later organization: `#star-sailors`, `#bumble`, `#roving`, `#station-198`

## Tips

- Name files with dates: `2025-11-07-quick-note.md`
- Use tags liberally
- Link to existing notes when relevant
- Don't let inbox grow too large - review weekly

## Moving Notes

When you're ready to organize:
1. Identify which project the note belongs to
2. Move to appropriate folder in `/Projects/`
3. Update any links
4. Delete from inbox
