# Star Sailors

**Type:** Web Application  
**Tech Stack:** React, Next.js, Supabase  
**Status:** Active Development

## Overview

Star Sailors is a citizen science platform that gamifies real astronomical data classification. Users deploy virtual telescopes, satellites, and rovers to discover and classify celestial objects and phenomena.

## Key Features

- **Telescope Missions** - Planet hunting, variable stars, disk detective
- **Satellite Missions** - Weather monitoring, solar health tracking
- **Rover Missions** - Mars exploration, mineral extraction
- **Classification System** - User-generated discoveries with consensus voting
- **Research Tree** - Unlock new capabilities and missions
- **Community** - Share discoveries, vote, comment
