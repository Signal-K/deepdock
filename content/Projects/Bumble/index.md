# Bumble

**Type:** React Native Mobile Game  
**Platform:** iOS, Android  
**Status:** Active Development

## Overview

Bumble is a relaxing farming and pollinator management game integrated with the Star Sailors ecosystem. Players grow crops, attract pollinators, and learn about different bee species.

## Key Features

- **Crop Management** - Plant, grow, and harvest various crops
- **Pollinator System** - Attract and learn about different bee species
- **Weather Integration** - Real weather affects crop growth
- **Achievements** - Weekly missions and long-term goals
- **Educational** - Learn about pollinators and agriculture

## Technical Details

- Built with React Native and Expo
- Sprite-based graphics (planned Godot migration)
- Integration with Star Sailors backend
- Local weather data integration
