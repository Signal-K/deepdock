# Ideas Routed from 2025-11-09.md

## Extracted Ideas
I would really like to do a space agency game at some point, but only if I can get a large number of assets and figure out some sort of narrative that sets it aside from other space agency games.

Mining? The low poly games like Astroneer look really good for mining and construction, but I have a feeling that working with 3D assets would heavily complicate development, and - it's already been done before.

I like the idea of a minimal automation game, with things like redstone and factories, workflows, etc. 
An obvious citizen science minigame would be finding asteroids and planets.

But I still would need to find a narrative...


I think that the Telescope sharing service (basically a clone of Foto) would be quite awesome, but probably the priority has to be building my audience. Bumble is just going to go the way of SS if I don't start getting a following.

Spending time on building my own writing platform is probably fine - until something happens with Decen, what is there for me to do, really? But publishing on something like Substack will just get me a larger audience out of the box. I think that's probably a better use of my time. 



When it comes to getting #Bumble out there in the world, I think I'm going to start distributing the `apk` file out tonight (09/11). We have the basics, AFAIK both Supabase clients have parity across the `anomalies` table(s). 
1. Does the current game loop make sense?
2. Does the classification process fit in (UI mainly - we're not getting rid of this)
3. Does it look good?
4. Does it run on android?

Getting something out for iOS will be much harder (well, I'll be able to test it myself as I can manually sideload the `ipa` onto my iPhone, but distribution will be effectively impossible until we get our Apple Developer license sorted).
