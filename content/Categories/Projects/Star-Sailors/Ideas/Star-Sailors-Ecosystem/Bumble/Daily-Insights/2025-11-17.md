In terms of the Godot build, here's where I'm at right now. Hotbar is visible!

I did realise that as long as we're using [born](https://github.com/borndotcom/react-native-godot) we'll be unable to have the Godot scenes run in a web interface. Or at least, in React Native outside of the native environment. This means that 1) we NEED native apps (and therefore the developer licenses) and 2) if we want to have the game be playable on desktop, it won't be running in React Native anyway. So if we need this, we will need to have Godot + Supabase directly integrated anyway.

This forces me to think a little bit about restructuring the ambition for the game. At least, we have to have a mobile-first UI. But a mobile game is something I'm still quite satisfied with building.
