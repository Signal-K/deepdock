## Extracted Ideas
So the first thing I'm working on today is getting the Expo version of #Bumble "dockerized". I have a little bit of time on the way to Bremen to get things started there and maybe continue building the functional components on the Node side.

I need to chat with Rhys and maybe Kriswanto to discuss the Product Hunt launch, because that is the area (as discussed I think yesterday [[2025-11-17]]) (if any) that the web #Star-Sailors client should focus on. Improving the user experience and maybe (once Dev and I can set up the licensing infrastructure) bringing things over to a native experience with React Native.

I'm still unsure about the Godot interface/integration for desktop environments - I would assume that things would perform better on RN/Expo, but if we (as I hope we do, eventually) create more graphically rich content in our games, not everything will be playable (easily) on mobile. Additionally, there is the additional fact that people will be accessing SS from desktop environments. No getting around that. Right now, 74% of visitors (this week) are coming from desktop (mac/windows) environments.

However, I do still think that we can probably get somewhere if we build native apps and launch them on the app store/play store, because the path to user integration is easier. 
So `godot-react-native` isn't the "perfect"/end solution for building these interfaces to, well, interface with Godot, but it's a convenient stop-gap while we build to get early users. Getting mobile gamers will be easier, I think, and it also makes sense for #Star-Sailors (current web) client to be mobile-first because that was the sort of point of the game in the early stages - a small thing to keep you occupied daily/weekly on commutes or similar times/environments. Plus, the `upload` mechanic is much easier to do on mobile devices.


I'm having a little think about what to do next....I think the functional side of things is what I should focus on. So....let's get some bee hives started.
Here's the flow:
1. Every user starts with one beehive
2. Every harvest increases your "pollination factor" (will need to rename this)
3. Once your pollination factor is > 5 (arbitrary value for now), bees start spawning. Bees will spawn depending on your current plants, harvest history, weather values, etc

The pollination events will just provide bonuses for now - THIS MUST CHANGE.

In terms of the Godot/game side of things, I'm going to have a go at designing new tilesheets: https://www.pixilart.com/draw. Then, we can start looking at templates for 3d vs 2d.
