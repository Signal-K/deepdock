## Project Status: Jovian Vortex Hunter (JVH)

JVH has been re-added as a selectable project. Users can now classify storms and vortexes on Jupiter once again. Classification type is fully integrated into the routing logic and UI.

We should evaluate the long-term rewards and research integrations for JVH classifications (e.g. storm pattern progression, gas composition tools).
