So, the following classification missions have tutorials, ripped from Zooniverse:
1. Planet Hunters
2. Daily Minor Planet
3. Active Asteroids
4. Cloudspotting on Mars
5. Planet Four
6. JVH
7. Sunspots

We do not have one for Cloudspotting on Mars: Shapes as far as I'm aware.

A global component should have the following content/props:
1. Tutorial paragraphs (textual slides separated into steps)
2. Tutorial image assets
3. `classificationtype` - to determine if the user has performed a classification of the type and therefore doesn't need to be shown the tutorial

We also need to maybe add the `$anomalyId` value and show the annotation window, or we just have it show up before the regular annotation window does.
